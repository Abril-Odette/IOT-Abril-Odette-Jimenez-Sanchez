LAB 03 · IOT SIMULATION

Smart Parking

Tec de Monterrey, Campus Querétaro

A simulated IoT system: every parking space has a virtual sensor that detects if a car is parked there. The data is not real, but it updates by itself and you can click any space to change it.

3. Reference photo

This is the real parking lot that inspired the project. My plan follows its main idea: five blocks of back-to-back parking spaces in the center, one-way lanes between them and single rows of spaces on the left, top and bottom.

Parking lot of Tec de Monterrey, Campus Querétaro (satellite view).

4. How it works

Parking spaces 215 spaces: 5 center blocks (A to E) with 2 sides each (L and R) and 18, 17, 17, 16 and 15 spaces per side, plus single rows on the left (21), top (15) and bottom (13, with an accessible space at each end).
Simulated sensors When the page opens, each space gets a random status (about 60% occupied).
Automatic updates Every 4 seconds, between 1 and 3 cars arrive or leave. Over time the lot slowly fills up and empties, like during a school day.
Manual changes Click on any space to change its status. The dashboard updates immediately.
Dashboard Total, occupied, available, percentage and a bar that changes color (green, orange, red) as the lot gets full.
Tools HTML for the structure, CSS for the design and JavaScript for the sensors, clicks and calculations.
